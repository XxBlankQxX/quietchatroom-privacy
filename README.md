# Quiet Chatroom – Data Deletion Policy

This app uses **Firebase Anonymous Authentication** and does not store any user-identifiable information.

## 🔒 What data is collected?

- Anonymous display names (e.g., Anonymous 1234)
- Chat messages
- Timestamp of messages

## 🧹 How to delete your chat data?

To delete all messages from the chatroom:

1. Open the app
2. Type:  //clearquietchatroommessages//
3. This will instantly delete all chat messages from the server.
